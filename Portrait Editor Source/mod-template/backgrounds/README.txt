CUSTOM PORTRAIT BACKGROUNDS

Put your screenshots directly in this backgrounds folder.
Supported formats: PNG, JPG, JPEG.
Recommended size: 512 x 512 pixels (square). 256 x 256 is also sufficient.
Maximum supported dimensions: 2048 x 2048 pixels.
Use simple filenames, for example mongrel.png or desert.jpg.
Avoid HUD elements in the screenshot.

Non-square pictures are cropped automatically from the centre to a square. Pictures are resized internally to the native portrait size, so larger images will not make the HUD portrait sharper. Keep files small; 512 x 512 is recommended.

Restart Kenshi after adding files. Right-click a squad portrait, choose Customize portrait, then use the arrows beside Background to choose your image and press Apply. Images appear after the built-in colour options in filename order.

The selected filename is saved per character. If an image is removed or renamed, its portrait returns to the default background after restarting.
